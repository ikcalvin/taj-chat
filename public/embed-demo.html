TAJ Assistant Chat Widget

This page demonstrates the embeddable chat widget. Click the chat button in the bottom-right corner to try it out.

Quick Start

Add this single line to your website, just before the closing </body> tag:

<script src="https://YOUR_DOMAIN/embed.js" data-taj-chat></script>

Configuration Options

<script
  src="https://YOUR_DOMAIN/embed.js"
  data-taj-chat
  data-taj-url="https://YOUR_DOMAIN"
  data-taj-position="right"
  data-taj-color="#b45309"
  data-taj-size="default"
></script>

data-taj-position: "right" or "left"
data-taj-color: Hex color for the launcher button
data-taj-size: "compact", "default", or "large"

JavaScript API

// Open the chat
TajChat.open();

// Close the chat
TajChat.close();

// Toggle the chat
TajChat.toggle();
